# Lasmondy Barber

Proyecto educativo inicial para aprender Flask, Jinja, HTML, CSS y JavaScript.

## Cómo iniciar el proyecto

1. Abrí una terminal dentro de esta carpeta.
2. Creá y activá un entorno virtual (opcional, pero recomendado).
3. Instalá la dependencia:

   ```bash
   pip install -r requirements.txt
   ```

4. Iniciá la aplicación:

   ```bash
   python app.py
   ```

5. Abrí `http://127.0.0.1:5000` en el navegador.

Por ahora solo existe la página de inicio. Las funciones de usuarios, turnos, servicios y base de datos se agregarán en etapas posteriores.
